# Follow Your Eye online collector

The website saves each choice before showing the next pair. The current dataset has 2,751 active pairs after a second image quality review removed 109 from the preceding 2,860-pair deck. Artwork records, existing AI judgments, and model predictions are preserved. Its version string keeps incoming records separate from earlier choices in the existing D1 `experience_choices` table. The former 60-pair public write route is retired; its separate `choices` table and existing records remain available through authenticated owner exports.

New choices store an approximate two-letter country code from Cloudflare's `request.cf.country` and the connecting IP from `CF-Connecting-IP`, or NULL when unavailable or invalid. The browser event body cannot provide or override either value. The current page sends the legacy `ipNoticeVersion: 1` marker; IP collection is described on the About page. Events queued by an older page lack that marker, still save normally, and keep NULL IP. An IP may represent a VPN, proxy or shared network and is not proof of a distinct person. The authenticated owner can view the IP and country with each choice; public vote totals expose neither. Earlier choices retain NULL IP and cannot be backfilled.

## Deployment order

1. Confirm the existing website and collector are healthy, and back up the production D1 database.
2. Publish the About-page data description in `web/` through GitHub Pages and verify it is publicly accessible before enabling IP storage. New installations use `schema.sql`; existing installations apply `migrate_experience_country.sql` if needed, then `migrate_experience_ip.sql` once. Do not delete earlier records.
3. Deploy the existing `follow-your-eye-collector` Worker with the checked-in code, existing D1 database ID, `ALLOWED_ORIGIN=https://vincentliu.ai`, and its private `ADMIN_TOKEN` secret. The Wrangler template disables preview URLs and enables observability logs.
4. Verify `/experience/health` reports `follow-your-eye-met-paintings-v3` with the allowed Origin. Register a fresh test session through `POST /admin/test-sessions`, save one choice through `/experience/choices`, inspect `/admin/experience-ips?environment=test` and `/admin/experience.csv?environment=test`, then delete only that test session through `DELETE /admin/test-sessions/<session-id>`. Confirm the CSV IP agrees with the database or is unknown.
5. Verify a browser choice and its test record, then clean up that registered test session. Keep production records.
6. Visitors with a cached old page may need to refresh after the new dataset version is deployed.

The browser validates the collector URL from `collection_config.json` and sends a choice directly; it does not require a separate health request before a visitor can select a painting. The next pair appears only after the save is acknowledged. A failed save remains queued on the device with a visible retry control. If the configuration itself is unavailable, choosing pauses with a retry control. Records from different deck versions remain separated by `dataset_version` in the same database. The public `/experience/community?pairs=id1,id2` endpoint counts only production A/B choices for the current version; it excludes skips, test records, country codes and IPs. The public `/experience/choice-count` endpoint returns only the total number of current-version production A/B choices for the About page's live count; it exposes no session, country or IP data and is marked `no-store`.

Administrator routes require `Authorization: Bearer <ADMIN_TOKEN>`. Keep the token outside the public repository. `node worker/owner_cli.mjs ips` shows production IP counts, anonymous session counts, and first/last receipt times; `ips-test` shows the test partition. `countries` and `countries-test` show coarse country totals. The CSV export includes `country_code` and `client_ip`; protect downloaded CSV files because IP addresses are personal data. The exporter currently reads matching rows in one request; before large-scale recruitment, replace it with a paginated exporter and validate D1 capacity.
